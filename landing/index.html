Copernicus Thermal Fronts

Autonomous daily satellite data ingestion from Copernicus Marine (CMEMS). A 2D Sobel gradient spatial filter detects sea surface temperature (SST) thermal boundaries ($d(SST)/dx \ge 0.015^\circ\text{C/km}$) intersected with chlorophyll-a concentration blooms.

ALGORITHM: SOBEL + NMS (15KM)
📶

Offline-First Pre-Departure

Off the coast of Mirissa, Galle, and Trincomalee, cellular coverage drops within 20km. The mobile application aggressively caches map tiles, detected PFZ coordinates, and a 24-hour marine weather forecast into embedded SQLite before cast-off.

ENGINE: SQLITE + FLUTTER MAP
🚨

Severe Weather & 2G SMS Fallback

Automated hourly marine wave evaluation (>2.5m warning, >3.5m danger). When vessels are offshore and have been disconnected from IP data for over 2 hours, the engine automatically escalates from FCM Push to 2G SMS coastal broadcast.

ALERTING: HYBRID PUSH + 2G SMS
🧭

Great-Circle Navigation

Real-time spherical Haversine distance in Nautical Miles (NM) and initial forward compass bearing in degrees ($^\circ$) with cardinal compass heading (e.g. SSE, WSW) from the boat's current GPS position to each identified fishing hotspot.

MATH: HAVERSINE & FORWARD AZIMUTH
☀️

High-Contrast Daylight UI

Designed specifically for harsh equatorial open-ocean glare. Features bold pure-black borders, safety yellow hazard banners, high-contrast maritime badges, and single-tap trilingual switching between Sinhala, Tamil, and English.

AESTHETICS: TROPICAL MARITIME

Enterprise Marine Security

Hardened FastAPI gateway backed by PostGIS spatial indexing (EPSG:4326), Redis caching, Celery task scheduling, JWT Bearer authentication, and SlowAPI rate limiting to safeguard national marine fisheries infrastructure.

SECURITY: JWT + SLOWAPI + POSTGIS
